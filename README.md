## ⚡ Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure Environment

Run the setup script to generate configuration:

```bash
python setup.py
```

This will:
- Generate `config.py` with WBL API credentials
- Create `.env` file from `.env.example`
- Set up database schema
- Validate configuration

### 3. Set Up Accounts

Create `credentials/accounts.yaml`:

```yaml
accounts:
  - username: "your@email.com"
    password: "yourpassword"
    chrome_profile: "Default"
    candidate_id: 0
```

### 4. Run Extraction

```bash
python main.py
```

## 📖 Usage

### Single Account Extraction

Extract contacts from one LinkedIn account:

```bash
python main.py
```

**Output:**
- `logs/extracted_contacts.csv` - CSV backup
- `logs/extraction_debug.log` - Detailed logs
- `data/contacts.duckdb` - Local database
- WBL API - Cloud storage (if configured)

### Multi-Account Extraction

Process multiple LinkedIn accounts automatically:

```bash
python main.py
```

The bot will:
1. Load all accounts from `credentials/accounts.yaml`
2. Process each account sequentially
3. Apply 10-20 second delays between accounts
4. Track success/failure for each account
5. Generate comprehensive summary

### Query DuckDB Analytics

```python
from utils.duckdb_manager import DuckDBManager

with DuckDBManager() as db:
    # Get recent extraction runs
    runs = db.get_recent_runs(limit=10)
    
    # Search contacts by company
    contacts = db.search_contacts(company='Google')
    
    # Get success rate trend
    trend = db.get_success_rate_over_time(days=30)
    
    # Get run metrics
    metrics = db.get_run_metrics(run_id=1)
```

## 💾 Data Storage

### 1. CSV Backup

**Location:** `logs/extracted_contacts.csv`

**Format:**
```csv
timestamp,source_email,full_name,company_name,location,email,phone,profile_url
2026-02-09 13:14:01,you@email.com,John Doe,Example Corp,"San Francisco, CA",john@example.com,+1234567890,https://linkedin.com/in/johndoe
```

**Purpose:** Immediate backup, Excel import, data recovery

### 2. WBL API (Cloud Storage)

**Endpoint:** `POST /api/vendor_contact/bulk`

**Features:**
- Bulk insertion (all contacts at once)
- Duplicate detection (by LinkedIn ID)
- Activity logging
- CRM integration

**Response:**
```json
{
  "success": true,
  "inserted": 5,
  "duplicates": 2,
  "failed": 0,
  "total": 7
}
```

### 3. DuckDB Analytics

**Location:** `data/contacts.duckdb`

**Tables:**
- `extraction_runs` - Run tracking and metrics
- `contacts` - All extracted contacts
- `extraction_failures` - Error logging

**Features:**
- SQL queries
- Analytics and trends
- Performance tracking
- Historical data

## 🔍 Troubleshooting

### Issue: Config Import Error

**Error:** `ImportError: cannot import name 'WBL_CONFIG' from 'config'`

**Solution:**
```bash
python setup.py
```

This regenerates `config.py` with proper WBL API configuration.

---

### Issue: Login Failures / 2FA Required

**Error:** Bot asks for 2FA or CAPTCHA

**Solution:**
1. Open Chrome with your profile manually:
   ```bash
   chrome.exe --profile-directory="Default"
   ```
2. Log into LinkedIn manually
3. Complete any 2FA verification
4. Close Chrome
5. Run bot again

---

### Issue: No Contacts Extracted

**Error:** "0 contacts extracted"

**Possible Causes:**
- No LinkedIn messages/conversations
- LinkedIn UI changed (selectors outdated)
- Network issues

**Solution:**
1. Check you have LinkedIn messages
2. Review `logs/extraction_debug.log`
3. Update selectors in `linkedin_selectors/selectors.py` if needed

---

### Issue: API Connection Failed

**Error:** "Cannot connect to API server"

**Solution:**

**For Local Testing:**
```bash
# Start your local WBL API server first
cd path/to/wbl-backend
uvicorn main:app --reload --port 8000
```

**For Production:**
- Verify `config.py` has correct API_URL
- Check TOKEN is valid
- Run `python setup.py` to regenerate config

---

### Issue: Duplicate Contacts Not Inserting

**Behavior:** Contacts marked as duplicates but not in database

**Explanation:** The API detects duplicates by `linkedin_id`. If a contact appears twice in the same extraction, only the first is inserted.

**Solution:** This is expected behavior to prevent duplicate entries.

---

### Issue: Activity Logging Fails (500 Error)

**Error:** `[LOG_ACTIVITY] Status Code: 500`

**Possible Causes:**
- Invalid `candidate_id` in payload
- Missing required fields
- API server error

**Solution:**
1. Check `config.py` has correct `CANDIDATE_ID`
2. Verify API server is running
3. Check API logs for detailed error

## 🔐 Security

### Best Practices

1. **Never commit credentials**
   - `credentials/accounts.yaml` is gitignored
   - `.env` is gitignored
   - `config.py` is gitignored

2. **Use Chrome profiles**
   - Keeps sessions isolated
   - Prevents cross-account contamination

3. **Rotate tokens regularly**
   - Update WBL API tokens periodically
   - Run `python setup.py` to update

4. **Monitor for detection**
   - Use reasonable delays
   - Don't exceed rate limits
   - Review LinkedIn account health
