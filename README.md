# LinkedIn Contact Extraction Bot

> **Automated LinkedIn inbox message extraction with multi-account support, NER-powered contact parsing, email validation, SMTP reporting, and stealth browsing.**

---

## 🚀 Features

- ✅ **Inbox Message Extraction** — Scrape all LinkedIn conversations and extract contact info
- ✅ **NER-Powered Parsing** — Dual NER engine (SpaCy + GLiNER) extracts name, company, job title, email, phone, location from message text
- ✅ **Email Validation** — Syntax + MX record validation before API submission
- ✅ **Multi-Account Support** — Process 50+ LinkedIn accounts sequentially, fully isolated
- ✅ **Stealth Mode** — Undetected ChromeDriver with human behavior simulation
- ✅ **Chrome Profile Optional** — Auto-generates isolated browser sessions per account
- ✅ **Dual API Submission** — Pushes contacts to `/automation-extracts` and positions to `/raw-positions`
- ✅ **SMTP Email Report** — Sends HTML run summary email with CSV attachment after each run
- ✅ **DuckDB Analytics** — Local database for historical tracking
- ✅ **Auto Token Refresh** — JWT token auto-refreshed on expiry from `.env`

## ⚡ Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure Environment

```bash
python setup.py
```

This generates `config.py` with WBL API credentials and validates the setup.

### 3. Set Up Accounts

Create `credentials/accounts.yaml`:

```yaml
accounts:
  - username: "your@email.com"
    password: "yourpassword"
    employee_id: 351
    candidate_id: 0
    # chrome_profile: "Default"   ← optional, auto-created if omitted
```

### 4. Run

```bash
# Full run (scrape + extract + submit to API)
python run_inbox_extraction.py
```

## ⚙️ Configuration

### Environment Variables (`.env`)

```bash
# WBL API  (auto-generated by setup.py)
WBL_API_URL=http://localhost:8000/api
WBL_EMAIL=you@example.com
WBL_PASSWORD=yourpassword
WBL_EMPLOYEE_ID=351
WBL_CANDIDATE_ID=0

# Execution
MAX_MESSAGES_TO_PROCESS=20
LOG_LEVEL=INFO

# SMTP Email Report (optional)
SMTP_ENABLED=false
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASSWORD=your_app_password
SMTP_FROM=LinkedIn Bot <your@gmail.com>
SMTP_TO=recipient@example.com
```

### Bot Configuration (`config.yaml`)

```yaml
NUM_MESSAGES_TO_PROCESS: 5
execution_limits:
  max_contacts: 50
  max_consecutive_errors: 3
  thread_delay_min: 3
  thread_delay_max: 8
```

### Account Configuration (`credentials/accounts.yaml`)

```yaml
accounts:
  - username: "account1@example.com"
    password: "password1"
    employee_id: 351
    candidate_id: 0
    # chrome_profile: "Profile 1"   ← optional

  - username: "account2@example.com"
    password: "password2"
    employee_id: 351
    candidate_id: 1
    proxy: "http://user:pass@proxy.host:8080"   # optional
```

> **`chrome_profile` is optional.** If omitted, the bot automatically creates an isolated browser session under `data/bot_profiles/<username>/`. Sessions persist between runs.

## 📖 Usage

### Inbox Extraction (Recommended)

Two-phase pipeline — scrape first, extract offline:

```bash
# Both phases (default)
python run_inbox_extraction.py

# Phase 1 only — scrape conversations to JSON
python run_inbox_extraction.py --phase 1

# Phase 2 only — extract contacts from existing JSON
python run_inbox_extraction.py --phase 2

# Limit conversations per account
python run_inbox_extraction.py --max-conversations 30

# Run specific account (0-based index)
python run_inbox_extraction.py --account 0

# Skip email report
python run_inbox_extraction.py --no-email
```


### Test SMTP Connection

```bash
python -c "from utils.email_reporter import EmailReporter; EmailReporter().test_connection()"
```

## 🔄 How It Works

### Phase 1 — Live Scraping (`run_inbox_extraction.py --phase 1`)

```
Login to LinkedIn (or resume saved session)
  → Navigate to /messaging/
  → Scroll sidebar to discover all conversations
  → For each conversation: extract all message bubbles
  → Save raw JSON to data/raw_messages/YYYY-MM-DD/<conv_id>.json
  → Close browser
```

### Phase 2 — Offline Extraction (`run_inbox_extraction.py --phase 2`)

```
Read all JSON files from data/raw_messages/YYYY-MM-DD/
  → For each conversation: run NER on message text
      ├── SpaCy:  names, emails, phones, job titles, companies, locations
      └── GLiNER: names, job titles, companies, locations (better for complex text)
  → Merge best fields from both engines
  → Validate emails (syntax + MX record check)
  → Deduplicate by email / LinkedIn ID
  → Write contacts to data/output/YYYY-MM-DD/inbox_contacts.csv + .json
  → Bulk submit to WBL API:
      ├── POST /automation-extracts/bulk  (contact identities)
      └── POST /raw-positions/bulk        (positional / company data)
```

## 💾 Data Storage

### 1. Raw JSON (Phase 1 output)
`data/raw_messages/YYYY-MM-DD/<conversation_id>.json`

### 2. Contacts CSV + JSON (Phase 2 output)
`data/output/YYYY-MM-DD/inbox_contacts.csv` — all extracted contacts

### 3. WBL API (Cloud)

| Endpoint | Data |
|---|---|
| `POST /automation-extracts/bulk` | Contact identities (name, email, phone, LinkedIn ID) |
| `POST /raw-positions/bulk` | Positional data (title, company, location) |

Response:
```json
{ "success": true, "inserted": 5, "duplicates": 2, "failed": 0 }
```

### 4. DuckDB Analytics (Local)
`data/contacts.duckdb` — historical runs, metrics, trends

### 5. CSV Backup
`logs/extracted_contacts.csv` — immediate CSV backup

## 📧 Email Reports

After each run the bot emails a **rich HTML summary** to the address in `SMTP_TO`.

**Report includes:**
- Overall stats: contacts found, API inserted, duplicates, failures, runtime
- Per-account breakdown table
- Top 10 contacts preview
- Error log (if any)
- Attached `inbox_contacts.csv`

**To enable:**

```bash
# In .env
SMTP_ENABLED=true
SMTP_USER=your@gmail.com
SMTP_PASSWORD=your_app_password   # Gmail → myaccount.google.com/apppasswords
SMTP_TO=recipient@example.com
```

**Test SMTP connection:**
```bash
python -c "from utils.email_reporter import EmailReporter; EmailReporter().test_connection()"
```

## 🔍 Troubleshooting

### Config import error
```
ImportError: cannot import name 'WBL_CONFIG' from 'config'
```
**Fix:** `python setup.py`

---

### Login fails / 2FA / CAPTCHA
Bot pauses and waits for you to solve it manually in the open browser window. Once you complete the challenge and see the LinkedIn feed, the bot resumes automatically.

---

### 0 contacts extracted
1. Confirm you have LinkedIn messages
2. Check `logs/inbox_extraction.log`
3. If selectors are outdated, update `linkedin_selectors/selectors.py`

---

### API connection failed
```bash
# For local testing — start WBL API first
uvicorn main:app --reload --port 8000
```
For production: verify `WBL_API_URL` and `WBL_EMAIL`/`WBL_PASSWORD` in `.env`, then run `python setup.py`.

---

### SMTP email not sending
1. Run `python -c "from utils.email_reporter import EmailReporter; EmailReporter().test_connection()"`
2. Check `SMTP_ENABLED=true` in `.env`
3. For Gmail: use an **App Password**, not your account password
4. Check `logs/inbox_extraction.log` for `[EMAIL]` lines
